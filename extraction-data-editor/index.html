REVIEW CHANGES

Unity에 반영할 변경 사항

반영 요청을 보내면 연결된 PC가 원본 충돌과 값의 유효성을 검사하고 백업 후 적용합니다. PC가 연결되지 않으면 대기하며, 실행 중인 게임은 재로딩이 필요할 수 있습니다.

수정될 원본 파일
    연결된 PC에서 원본 검사·백업 후 적용합니다.
    IMPORT CSV

    CSV 가져오기

    현재 선택한 카테고리의 CSV를 불러옵니다. ID와 원본 정보는 유지하고 편집 가능한 값만 변경합니다. 가져온 값은 검토 전까지 임시 변경으로 남습니다.
    WEB HISTORY

    저장 및 반영 기록

    웹 저장과 연결 PC의 반영 결과입니다.

    CSV TRANSFER

    CSV로 PC 이동

    원본 프로젝트 PC가 연결되어 있지 않아도, 변경값을 파일로 옮겨 나중에 반영할 수 있습니다.

    1. 01
      다른 PC의 웹에서 편집

      비밀번호로 편집 잠금을 해제하고 필요한 값을 바꿉니다.

    2. 02
      변경값 CSV 내려받기

      모든 카테고리에서 바꾼 값을 파일 한 개에 담습니다. 아직 저장하지 않은 변경도 포함합니다.

    3. 03
      프로젝트 PC에서 가져와 반영

      ‘데이터 편집기 열기.cmd’로 로컬 편집기를 열고 이 메뉴에서 CSV를 가져옵니다. 비교 화면의 ‘검토한 변경을 게임에 반영’을 누르면 백업 후 적용합니다.
    OWNER ACCESS

    편집 잠금 해제

    열람은 누구나 가능합니다. 소유자 비밀번호를 입력하면 수정·저장·Unity 반영을 요청할 수 있습니다.
